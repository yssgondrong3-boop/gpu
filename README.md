# GPU Dash

Aplikasi Android pengecek performa CPU/GPU bertema dashboard mobil sport.

## Cara membuat APK lewat GitHub
1. Buat repositori baru di GitHub.
2. Upload semua isi folder ini, termasuk folder `.github`.
3. Buka tab Actions, pilih "Build APK", lalu Run workflow.
4. Setelah selesai, unduh artifact "GpuDash-apk", ekstrak, lalu install file `.apk`-nya.

## Catatan
- Skor GIPS adalah skor relatif untuk membandingkan hasil di HP yang sama.
- Clock per core dan beban GPU bergantung pada HP. Kalau tidak bisa dibaca, nilainya tampil 0 atau diperkirakan dari FPS.
